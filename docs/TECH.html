二、工程故事（评审看点）

1. 用数学探针定位"用户说不清"的视觉 bug

用户吐槽草原"内芯比外圈稀"。人眼审图两轮无果后，我们改用顶点数据分箱统计： 按半径把 6.8 万株草的分布拆成密度直方图，实测 [47.7, 61.3, 77.9]——外圈密度反超内圈 60%。 根因是分布公式 r = √u·R·(1−k·u) 的线性收缩让 dr/du 越靠外越小。修复为纯 √u 均匀分布 + 拒绝采样羽化边缘，复测 [50.7, 56.2, 56.5, 56.7]。可复现随机种子保证每次刷新贴图 完全一致，所有数字都能在自动化回归里复现。

2. brownout 沙暴：先查文献，再做标定

"伸手不见五指"不是美术词。依据陆军航空文献（下洗涡卷扬 + 地效再循环 + 桨尖涡扬沙） 建立悬浮尘墙模型；雾密度按透射率公式标定：机体 15u 保留 57% 轮廓可辨、25u 遮蔽 77%、 35u 遮蔽 94%。上升沿 1.5 秒（地效再循环建立过程），脱离快退。测试断言的是 雾密度物理量（0.0034→0.0373）而非截图观感。

3. 测出来的"玩具枪"，改出来的实战音效

初版武器音效用锯齿波扫频——评审第一反应就是"游戏激光"。全部推倒重做为 纯噪声 + 滤波合成：机炮方波 110→45Hz 加噪声爆点、地狱火弹射砰加低通尾焰、 爆炸分级（机炮/火箭/地狱火三档）。没有任何采样文件，全部由 Web Audio 实时合成。
